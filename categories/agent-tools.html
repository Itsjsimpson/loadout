Social posting

Postiz

Agent Toolspaid

Social media scheduler with a hosted MCP server, CLI, public API and webhooks on every plan, so agents can schedule posts across X, LinkedIn, Instagram, TikTok, YouTube, Bluesky and more.

Best for: Letting an agent post to social channels for you

Pricing: From $29/mo (Standard, 5 channels); 7-day free trial. MCP, CLI and API on every plan. Source

Ayrshare

Agent Toolspaid

Social media API for products and AI platforms: post, schedule, pull analytics and moderate comments across 14+ networks, billed per social profile.

Best for: Apps that post to social on behalf of their users

Pricing: Premium $149/mo (1 profile); Launch $299/mo with 28-day free trial; Business from $599/mo. Source

Email

Resend

Agent Toolsfreemium

Email API for developers with transactional and marketing email, plus inboxes your agents can send, receive and reply from via API and MCP.

Best for: Giving an app or agent a reliable email API

Pricing: Free: 3,000 emails/mo (100/day); Pro from $20/mo for 50,000 emails. Source

AgentMail

Agent Toolsfreemium

Email inboxes built for AI agents, with an API, SDKs, an MCP server, threads, drafts, webhooks and custom domains.

Best for: Giving each agent its own inbox

Pricing: Free: 3 inboxes, 3,000 emails/mo; Developer $20/mo; Startup $200/mo. Source

Payments

Stripe

Agent Toolspaid

Payments platform with an MCP server, agent plugin and agent skills, plus tools to sell through agents and accept agent-initiated payments.

Best for: Letting agents work with payments, billing and checkout

Pricing: 2.9% + 30¢ per successful domestic card transaction; no setup or monthly fees. Source

Phone and voice

Twilio

Agent Toolspaid

Communications APIs for voice calls, SMS, WhatsApp and verification, plus Conversation Relay for plugging voice AI into calls.

Best for: Phone numbers, calls and texts for an agent

Pricing: Pay as you go: calls from $0.014/min outbound, SMS from $0.0083/message. Source

Vapi

Agent Toolsfreemium

Developer platform for building voice AI agents that make and take phone calls; pick your own transcriber, model and voice providers.

Best for: Building custom voice agents on the phone

Pricing: $0.05/min Vapi hosting plus provider costs; $5 free credits to start. Source

Bland AI

Agent Toolsfreemium

AI phone call platform with one per-minute rate that covers the model, transcription and voice; bring your own Twilio or SIP or use Bland's.

Best for: Phone agents with simple all-in pricing

Pricing: Start: $0.14/min, $0 platform fee, no card required; Build: $0.12/min + $299/mo. Source

Browsing and web data

Browserbase

Agent Toolsfreemium

Cloud headless browsers for agents, plus Search and Fetch APIs; makers of the open-source Stagehand browser-agent SDK.

Best for: Running fleets of browsers for web agents

Pricing: Free plan (1 browser hour); Developer $20/mo; Startup $99/mo. Source

Browser Use

Agent Toolspaid

Cloud browsers and browser agents that complete web tasks, billed pay-as-you-go with no subscription.

Best for: Cheap pay-as-you-go browser agents

Pricing: Pay as you go: browsers $0.02/hour; agents at model cost + 20%; top-ups from $5. Source

Firecrawl

Agent Toolsfreemium

Web data API that searches, scrapes, crawls and maps sites into LLM-ready content for agents.

Best for: Turning web pages into clean data for an agent

Pricing: Free: 1,000 credits/mo; Hobby $19/mo ($16/mo billed yearly). Source
