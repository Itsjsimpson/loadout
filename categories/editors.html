AI code editor and coding agent platform; hand off tasks to agents or code alongside them.

Devin Desktop (formerly Windsurf)

AI Code Editors & IDEsfreemium

Cognition's IDE (Windsurf renamed June 2026) with an Agent Command Center for managing local and cloud agents.

Best for: Managing multiple agents from a full IDE

GitHub Copilot

AI Code Editors & IDEsfreemium

AI pair programmer in VS Code, JetBrains and GitHub, with chat and agent mode.

Best for: Teams already living on GitHub

Zed

AI Code Editors & IDEsfreemium

Fast, Rust-built collaborative code editor with built-in AI assistance.

Best for: Speed-focused devs who want AI without bloat

JetBrains Air

AI Code Editors & IDEsfreemium

JetBrains' agentic development environment for running Claude Agent, Codex, Junie, Copilot and ACP agents, in IDEs, browser or CLI.

Best for: JetBrains users orchestrating coding agents

Kiro

AI Code Editors & IDEsfreemium

AWS's agentic IDE built around spec-driven development.
