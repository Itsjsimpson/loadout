A plain-English guide to Codex, Claude Code, Cursor, Lovable, Bolt, Replit and v0 for first-time builders, using official prices and advice from builders who have shipped.

Quick answer

Already paying for ChatGPT? Start with Codex. It's already in your plan. OpenAI says Codex is included in ChatGPT Free, Go, Plus, Pro, Business, Edu and Enterprise. On Plus ($20/month) you get it on the web, in the terminal (CLI), in your code editor (IDE extension) and on iOS (OpenAI pricing, checked Oct 17, 2026).

  • Want to read and own your code? Codex, Claude Code or Cursor.
  • Can't code at all and want a clickable app fast? Lovable or Bolt. Plan to move to a code tool once you add login, payments and a database.
  • The most repeated tip from builders: pick one tool, save your work with git often, and don't switch until version 1 ships.

That last tip came up again and again when a first-time builder asked this exact question on X. He already paid for ChatGPT, kept seeing Cursor, Claude Code, Lovable, Bolt and Replit everywhere, and was building by pasting code from ChatGPT into VS Code by hand. If that sounds like you, the biggest step up is a tool that edits the files for you, so you stop copying and pasting.

The real pains, from builders who answered

Paraphrased from public replies on X. We left out replies from people who run tool-directory or ranking sites.

  1. AI "fixes" one thing and breaks three others. Commit to git before every big AI change, and after every step that works, so you can roll back in seconds when it goes sideways.
  2. App builders feel fast until you need to change something. Several builders said Lovable or Bolt can get you a clickable demo by the weekend, but login, billing, webhooks, database changes and the first strange bug are where you want your own code files.
  3. "It works on my computer" but breaks when it goes live. One builder said most of that pain comes from setup like the site URL, secret keys and database access rules, not from the tool. Fix those before you spend money on ads.
  4. Tool-hopping. Switching tools mid-build costs more than any difference between them, and whichever one you pick, you'll be tempted to switch again in two weeks.
  5. Picking for day 1 instead of month 3. Choose the tool you can still live with once the app is real. One builder uses Lovable to get the first screen live and connected to a database, then moves to Cursor from day 2.

A solo builder said they would pick Claude Code again if they had to start over, because most of their small apps are built in it.

FAQ

Do I need to pay for another tool if I already have ChatGPT?

Not to start. OpenAI says Codex is included in ChatGPT Free, Go, Plus, Pro, Business, Edu and Enterprise plans. Try it before you buy anything else. (source, checked Oct 17, 2026)

Is Claude Code free?

No. Claude Code is included in Claude's paid plans (Pro and up) and isn't on the Free plan. (source, checked Oct 17, 2026)

Can I start in Lovable or Bolt and switch later?

Yes. Several builders suggested exactly that: build a clickable version first, then move the code to GitHub and keep going in a code tool when you need login, payments and a database. Moving takes work, so do it once, on purpose.

What's the one habit that saves beginners the most pain?

Save your work with git after every step that works. When the AI breaks something, you can go back in seconds.

Which tech stack should I pick?

One builder's advice: pick a boring, popular stack such as Next.js with Postgres, because the AI has lots of examples of it to learn from.
